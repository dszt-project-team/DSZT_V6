# DSZT_V6 A 板接线表

更新时间：2026-09-26；适用定版 `v6-28deg-baseline-20260926`。

适用 RoboMaster A 型板 STM32F427IIH6。左右按 **V6 默认前进方向，站在车后向前看**。下列脚号已对照当前源码及本项目 A 板原理图 PDF 第5、8、9页（图框Sheet 6、9、10）。插头从线侧和插合侧看会镜像，必须按实物1脚标记计数，不能凭照片左/右数脚。

当前配置：左J31、右J26双转向闭环，软件零点3189/3073，两侧编码器健康强制检查；零油门满舵内轮28°、外轮20.32°，输出轴目标76.13°/66.92°，目标/反馈保护80°/82°。OID控制与安全逻辑见[项目Wiki](../DSZT_V6_项目总Wiki.md)。

**两个轮毂电机（经各自OID）和两个转向电机，动力全部由独立供电板提供，不从A板取动力电。** A板只承担控制/反馈/通信；A板PGND与对应信号参考地共地，动力回流走供电板，不走A板细信号地。

## 1. 两台 5840 转向电机

| 电机线/信号 | V6左前轮 | V6右前轮 |
|---|---|---|
| 蓝：PWM输入 | J31-5 / PI5 / TIM8_CH1 | J26-1 / PD12 / TIM4_CH1 |
| 黄：FG速度反馈输出 | J31-6 / PI6 / TIM8_CH2 | J26-2 / PD13 / TIM4_CH2 |
| 白：FR方向输入 | J31-7 / PI7 | J26-3 / PD14 |
| 绿：BRK刹车输入 | J31-8 / PI2 | J26-4 / PD15 |
| 红：动力正极 | 独立供电板24 V分支正极，不接A板 | 同左，独立分支 |
| 黑：动力负极/信号参考 | 独立供电板分支负极，并与A板PGND共参考地 | 同左，独立分支 |

线色依据本项目5840线序说明，实物若换线束以端子信号为准。**黑线必须接通，不能只接PWM/FR/BRK。动力回流不得走细信号地线。**

J31、J26蓝色8针排针全是信号，不提供电机电源。相邻 J30、J25 是PGND排针，可作信号地参考；J29、J24红色排针是可调电源 `VCC_5V_ADJ`，不是24 V，也不能未经测量用于编码器供电。

PWM低电平运行有效，0‰为全高停止；J31为50 kHz、J26为25 kHz。FR/BRK开漏，BRK低电平刹车。POWER2_CTRL/PH3上电置高，但不代替电机动力正负线及实际电压检查。

## 2. 两只 MT6826S 编码器

| 编码器信号 | 左前电机上的编码器 | 右前电机上的编码器 |
|---|---|---|
| OUT/PWM | **J31-1 / PA0 / TIM2_CH1** | **J26-6 / PH11 / TIM5_CH2** |
| GND | A板PGND，可用J30地排针 | A板PGND，可用J25地排针 |
| VCC | 按实际编码器模块额定电压供电 | 同左 |

编码器 **OUT不是电机FG**：左OUT接J31-1，不能接J31-6；右OUT接J26-6，不能接J26-2。两侧电机与各自编码器不可交叉。

编码器模块VCC规格及插件线序须按实物确认，不统一指定为5 V或3.3 V。若模块明确支持3.3 V，可使用板上TP_1=`VCC_3V3_O`、TP_2=PGND；接入前确认OUT电平与MCU输入兼容。不可直接接24 V或未经确认的J24/J29可调电源。闭环使用OUT/PWM，不使用SPI/ABZ。

当前两侧零点已确认，UART7应显示 `cal=0、sh=1/1、zero=1/1`；`ang`是相对软件零点的输出轴角，不是实际轮胎角。任侧编码器离线禁止闭环输出。

## 3. 飞控 MAIN1 / MAIN2

| 飞控侧 | A板接口 | MCU | 用途 |
|---|---|---|---|
| MAIN1信号S | **J34-7** | PB0 / TIM3_CH3 | 行走PWM，1260/1502/1770 μs |
| MAIN2信号S | **J34-9** | PB1 / TIM3_CH4 | 转向PWM，1000/1500/2000 μs |
| MAIN信号GND | **J34-20 / PGND** | GND | 必须共地 |
| MAIN电源正极 | 不接上述信号针；飞控按自身供电方案 | — | 不把5 V接到PB0/PB1 |

MAIN是PWM信号，不是串口。使用与3.3 V MCU输入兼容的信号电平。AUTO需要两路在线、两轴回中200 ms及SBUS授权；行走与转向仍受各自安全门约束。

## 4. OID通信

两台OID的485并到同一个自动换向TTL-485模块，模块接A板 **USART3 / J2**，115200 8N1。左OID ID=1、右ID=2。

| A板/模块 | 对端 |
|---|---|
| **J2-2 / PD8 / USART3_TX** | 模块TTL侧 **RXD（输入/DI）** |
| **J2-3 / PD9 / USART3_RX** | 模块TTL侧 **TXD（输出/RO）** |
| **J2-1 / PGND** | 模块GND；两OID通信地按原接法共参考 |
| J2-4 | **NC，不能取5 V** |
| 模块A/D+ | 左、右OID的485 A并接 |
| 模块B/D− | 左、右OID的485 B并接 |

上述RXD/TXD名称按本项目模块 `详情_19.jpg` 的箭头核对；不是同名TX接TX。模块供电沿用原接法；本项目模块说明推荐5 V，A板可用J15-1=`VCC_5V_U`、J15-2=PGND，接前核对实物。自动换向模块不接MCU DE/RE。

两台OID各自连接已适配轮毂的U/V/W和G/HU/HV/HW/+5V，保持相线/霍尔组合及电机配对不变。不接ABZ、不找Z。方向在各驱动器适配，MCU为+1/+1；关键速度参数见[Wiki第7节](../DSZT_V6_项目总Wiki.md#7-oid-驱动控制)。

两台OID的动力输入接独立供电板，按各自驱动器/轮毂额定电压供电，不从A板取电。模块5 V是通信模块电源，不是轮毂动力电源。

## 5. 金属探测盘：UART8预留

| 探测盘侧 | A板接口 | MCU |
|---|---|---|
| 盘TX（若为兼容TTL串口） | **J37-4 / UART8_RX** | PE0 |
| 盘RX（若需要接收命令） | **J37-3 / UART8_TX** | PE1 |
| 信号GND | **J37-2 / PGND** | GND |
| 电源 | J37-1为板上5 V，**只有盘额定电压/电流允许才使用** | VCC_5V_U |
| 可选事件输出 | J34-8 | PC2输入，目前应用不读取 |
| 可选使能输入 | J34-10 | PC3输出，上电低，目前应用不切换 |

**UART8目前仅初始化为115200 8N1，没有探测盘协议、接收IRQ/DMA或数据解析，接上不能视为已可工作。** 盘的串口电平、波特率、协议、供电规格仍需按具体设备确认。RS232/RS485不能直接接J37的TTL引脚，需匹配转换模块。PC2/PC3不是串口TX/RX。

## 6. 诊断、遥控和其他接口

| 模块 | 接线 |
|---|---|
| UART7诊断，115200 8N1 | **J38-3 / PE8 TX→USB-TTL RX；J38-4 / PE7 RX←USB-TTL TX；J38-2 GND↔GND** |
| J38电源 | Pin1=5 V；板子已独立上电时，USB-TTL VCC不接，避免双供电 |
| MC7 SBUS | J43-3信号、J43-2为5 V、J43-1为GND；板上反相链到PB7/USART1_RX，100000 8E2 |
| 左WS2812数据 | J27-1 / PA8；J27-3 PGND；Pin2 NC，灯带电源单独按额定值接 |
| 右WS2812数据 | J33-1 / PE14；J33-3 PGND；Pin2 NC，灯带电源单独按额定值接 |
| 板载蜂鸣器 | PH6/TIM12_CH1，无需外接 |
| USART6预留 | J36-3/PG14 TX、J36-4/PG9 RX、J36-2 PGND；无RK3566遥测任务 |
| USART2预留 | J18-4/PD5 TX、J18-3/PD6 RX、J18-2 PGND；无业务任务 |

UART7支持 `DBG GENERIC`、`DBG OID`、`DBG SBUS`、`DBG MT6826S`、`DBG FC`、`DBG OFF` 和 `DBG?`，大写加换行。命令只切日志，不切控制模式。NVIC当前优先级5，使用中断收发。

## 7. 接线检查

1. 断电核对脚号、电压和极性；J31/J26只接信号，电机红黑线走独立动力分支，信号共地。
2. 左电机与左编码器成对接J31，右侧成对接J26；当前零点3189/3073仅适用于已标定的机构，拆装后重新标定。
3. CH5锁车、CH1/CH3回中；检查UART7编码器视图 `cal=0、sh=1/1、zero=1/1、sf=0`；`encgate=0`仅是保留的开环旁路配置。锁车时应为`en=0、tgt=0,0、spd=0,0、stopf=0`；当前参数确认`param=1`。
4. 双闭环释放后中位会主动回零；保护为输出轴软件门限，不代替机械止挡。若另切开环，仅短点动，开环不执行闭环角度保护。
5. 只在架空且可立即断电时做分项联调；回中/锁车仍持续转动立即断动力，不反复解锁尝试。当前`stopf`固定为0，不能据此排除其他故障；在安全前提下记录`sm/fault/online/tgt/tx/spd`定位。未知供电项不可靠试插确定。
