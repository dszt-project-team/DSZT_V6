# DSZT_V6 轮毂电机接线定义与参数边界

左右轮毂电机的基础接法相同，每只电机共 8 根线：3 根动力三相线和 5 根霍尔信号/供电线。

| 线束 | OID 端子 | 当前参考线色 |
|---|---|---|
| 动力三相 | U / V / W | 绿 / 黄 / 蓝 |
| 霍尔 | G / HU / HV / HW / +5V | 黑 / 绿 / 黄 / 蓝 / 红 |

注意：

- 三相线和霍尔线都包含绿/黄/蓝，必须按线束、线径和插件区分；
- 霍尔 +5V 使用 OID 传感器供电，不接 A 板 3.3V；
- 改动 U/V/W 或 HU/HV/HW 后，必须重新辨识并保存该侧 OID 参数；
- V6 不使用 ABZ A/B/Z，上电不执行找 Z；
- 左右前轮装车方向与 V4.1.0 相反布置关系不能直接继承，禁止用旧工程的 ID、方向或 `m_invert_direction` 结论替代 V6 实车确认。

本目录“左轮/右轮”中的XML和截图为车主提供的V6轮毂适配资料，须保持驱动器与各自电机成对使用；不是任意同型号电机的通用出厂参数。固件不覆盖电机辨识数据。

当前确认的关键参数：左OID地址1、右OID地址2；前进方向已在各驱动器设置，MCU方向系数+1/+1；最大转速4900 ERPM，速度环加/减速度均4900 ERPM/s，心跳超时均1000 ms。`CHASSIS_PARAMETERS_CONFIRMED=1U`、`CHASSIS_OID_OUTPUT_ENABLE=1U`，非零输出仍受动态安全门控制。

固件主链直接使用ERPM，不另乘极对数；底层机械RPM换算接口保留14极对配置。换电机、驱动器或相线/霍尔组合后，需重新辨识、核对方向并导出该侧资料。XML不包含全部应用配置，特别是心跳超时和通信地址应在驱动器上位机另行核对。详细控制与时序见[项目Wiki](../../DSZT_V6_项目总Wiki.md#7-oid-驱动控制)。
