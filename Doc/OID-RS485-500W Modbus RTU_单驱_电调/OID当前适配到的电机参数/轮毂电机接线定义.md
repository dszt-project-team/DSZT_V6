# DSZT_V6 轮毂电机接线定义与参数边界

左右轮毂电机的基础接法相同，每只电机共 8 根线：3 根动力三相线和 5 根霍尔信号/供电线。

| 线束 | OID 端子 | 当前参考线色 |
|---|---|---|
| 动力三相 | U / V / W | 绿 / 黄 / 蓝 |
| 霍尔 | G / HU / HV / HW / +5V | 黑 / 绿 / 黄 / 蓝 / 红 |

注意：

- 三相线和霍尔线都包含绿/黄/蓝，必须按线束、线径和插件区分；
- 霍尔 +5V 使用 OID 传感器供电，不接 A 板 3.3V；
- 改动 U/V/W 或 HU/HV/HW 后，必须重新辨识并保存该侧 OID 参数；
- V6 不使用 ABZ A/B/Z，上电不执行找 Z；
- 左右前轮装车方向与 V4.1.0 相反布置关系不能直接继承，禁止用旧工程的 ID、方向或 `m_invert_direction` 结论替代 V6 实车确认。

本目录下“左轮/右轮”中的既有参数文件来自旧车参考，只能用于核对 OID 字段和初始辨识方法，当前不是 V6 的已确认参数。V6 源码仍以 ID 1/2、方向 +1/+1、14 极对作为编译占位，并由 `CHASSIS_PARAMETERS_CONFIRMED=0U` 禁止非零速度。

V6 首车必须逐台重新确认：Modbus ID、极对数、相序/霍尔表、正 ERPM 对应车辆前进方向、限流、速度环和加减速斜坡。确认后分别导出左右参数文件并更新 `application/chassis/chassis_config.h`、项目总 Wiki 和接线手册。
