# DSZT_V6 双转向与前驱差速参数

更新时间：2026-09-25。配置依据：`application/chassis/chassis_config.h`、`dual_steer.c`；本文为当前参数说明，不是硬件验收记录。

## 1. 固定基线

两根转向连杆所在的一面为车头；左右按站在车后朝车头看定义。前轴双5840转向、双MT6826S反馈、双OID轮毂驱动，后轴固定从动；无舵机、前后切换或外八。

| 项目 | 固定值 |
|---|---:|
| 轴距 L | 610 mm |
| 前/后轮距 | 500 / 500 mm |
| 左编码器软件零点 | 3148（J31，PA0/TIM2_CH1） |
| 右编码器软件零点 | 3006（J26，PH11/TIM5_CH2） |
| 零油门满舵内/外轮目标 | 18° / 14.390747° |
| 对应内/外输出轴目标 | 48.937636° / 47.388730° |
| 输出轴目标保护 | 53° |
| 输出轴反馈保护 | 55° |
| 满舵内/外前驱速度比 | 0.804271189 |
| 满舵后轴中心转弯半径 R | 2.127386958 m |
| 满舵内/外前轮滚动半径 | 1.974001466 / 2.454397838 m |

这里的轮角是模型目标；当前连杆比例为内侧33°→89.719°、外侧25°→82.325°。33°/25°是固定映射参考，不是本版满舵角；不能把参考分母随满舵角一起改。真实轮角及机械余量须按实物测量。

## 2. 阿克曼换算

结构调整参考（非当前配置）：内轮33°时，外轮约22.97°，按现有连杆模型对应输出轴约89.72°/75.63°。采用该行程前须重新确认机械范围、连杆映射和保护阈值；仅把满舵角改为33°会触发当前53°/55°保护。

```text
a = L / tan(delta_inner)
R = a + W/2                  # 后轴中心到瞬心
delta_outer = atan(L / (a + W))
r_inner = sqrt(L² + a²)
r_outer = sqrt(L² + (a + W)²)
speed_inner = speed_base * r_inner/r_outer
speed_outer = speed_base
shaft_inner = delta_inner * 89.719 / 33
shaft_outer = delta_outer * 82.325 / 25
```

W是前轮距；后轮距只记录，不参与前轴共瞬心计算。差速比例由代码实时计算，无需写入固定0.804271189常量。直行比例为1/1，倒车只改变共同速度符号。

|---|---:|---:|---:|---:|
| 左转 | -18° | -14.390747° | -48.937636° | -47.388730° |
| 右转 | +14.390747° | +18° | +47.388730° | +48.937636° |

## 3. 控制与限位

- 当前双闭环：`CALIBRATION_SIDE=0`、`CLOSED_LOOP_ENABLE=1`，两侧零点确认均为1。零点存固件，不写编码器NVM、不自动以上电位置标零。
- 两侧`SENSOR_INVERT=1`、`POSITIVE_REVERSE=1`；左转摇杆1257 us对应负转向量，左右接口不交换。
- 正常CH1为10 ms三点均值。转向轴角目标按300°/s独立限速；OID差速命令按1.6/s独立限速。差速根据处理后的转向指令计算，不用编码器实测轴角反算；两通路稳态一致，瞬态可能不同。
- 命令转向增益1～0.70，基于绝对行走命令并计入CH7，非实测车速。4900 ERPM满行走命令时满舵内轮为12.6°；零油门为18°。
- 位置环Kp=22‰/°，普通停止/重启误差3°/5°；目标绝对值≤1°时回中误差4.5°/7°。duty范围300～1000‰、每10 ms变化50‰，闭环换向等待50 ms。
- 上层检查目标绝对值>53°即故障；运行反馈绝对值>55°触发故障。位置环另有目标绝对值>55°的兜底校验。任侧故障停双侧并锁存，CH5锁车清上层锁存后仍需重新健康、回中释放。等于阈值不触发“大于”检查；阈值不是硬件限位开关。
- 最大正常轴目标48.937636°低于53°约4.06°、低于55°约6.06°，这是模型余量，不是制动距离保证。禁止依靠软件保护替代机械止挡及可断动力措施。
- 单轮开环1左/2右仅为保留调试功能；此时250～450‰、换向前后各300 ms，回中停、不执行闭环角度保护。`CAL_REQUIRE_ENCODER_HEALTH=0`只影响开环，当前双闭环强制检查两侧编码器。

## 4. OID配置与适用范围

`CHASSIS_PARAMETERS_CONFIRMED=1`、`CHASSIS_STEER_LINKAGE_CONFIRMED=1`启用当前模型；`CHASSIS_OID_COMMISSION_MAX_ERPM=0`不附加速度限制。动态安全门、停车监督和通信时序见[Wiki第7节](../DSZT_V6_项目总Wiki.md#7-oid-驱动控制)。

左OID ID=1、右ID=2，经同一个TTL-485模块接A板USART3/J2；方向在各驱动器处理，MCU +1/+1；速度环加/减速度均4900 ERPM/s、最大转速4900 ERPM，CH7最高4900 ERPM。

几何模型假设两前轮绕共同瞬心纯滚动；将路径比例直接用于ERPM还要求两侧轮毂电气参数及有效轮径一致。模型和软件保护不能替代机械限位、方向、停车及失联恢复检查。
