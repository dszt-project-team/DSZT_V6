# DSZT_V6_FC A 板接线表

A 板为 STM32F427IIHx。左右按站在车后面向车头定义，前轴为驱动/转向轴。接口沿用 V6 A 板定义，与本工程 GPIO/定时器配置一致；更换板卡、线束或模块后，仍须核对实物丝印、电平和供电，不能只按线色连接。

## 运动与输入

| 模块 | A 板接口 / MCU | 对端 |
|---|---|---|
| 左 5840 PWM | J31-5 / PI5 / TIM8_CH1 | 左转向驱动 PWM |
| 左 5840 FG | J31-6 / PI6 / TIM8_CH2 | 左驱动 FG；不是编码器 OUT |
| 左 5840 FR / BRK | J31-7 / PI7；J31-8 / PI2 | 方向 / 刹车 |
| 右 5840 PWM | J26-1 / PD12 / TIM4_CH1 | 右转向驱动 PWM |
| 右 5840 FG | J26-2 / PD13 / TIM4_CH2 | 右驱动 FG |
| 右 5840 FR / BRK | J26-3 / PD14；J26-4 / PD15 | 方向 / 刹车 |
| 左 MT6826S OUT | J31-1 / PA0 / TIM2_CH1 | 左编码器 PWM 输出；地接 J30 GND |
| 右 MT6826S OUT | J26-6 / PH11 / TIM5_CH2 | 右编码器 PWM 输出；地接 J25 GND |
| 飞控 MAIN1 S | J34-7 / PB0 / TIM3_CH3 | 行走 PWM |
| 飞控 MAIN2 S | J34-9 / PB1 / TIM3_CH4 | 转向 PWM |
| 飞控 GND | J34-20 | 与飞控信号地相连；不把电源正极接至信号脚 |
| OID 转换模块 RXD / DI | J2-2 / PD8 / USART3_TX | A 板发送到 TTL 转 485 模块接收 |
| OID 转换模块 TXD / RO | J2-3 / PD9 / USART3_RX | 模块发送到 A 板接收 |
| OID 信号地 | J2-1；J2-4 不接 | 模块 GND；两台 OID 共用 485 总线 |

两个 OID 的 485 并联接转换模块，再接 USART3，115200、8N1，左地址 1 / 右地址 2。使用自动收发转换模块，软件没有 DE 控制线；模块供电按额定要求，可用相符的 J15-1 5V-U / J15-2 GND。方向已在 OID 内适配，软件左右均为 +1。

两个轮毂和两个转向电机均由独立供电板供电，不从 A 板取电机动力；**驱动器、编码器、飞控与 A 板必须可靠共信号地**。编码器及灯带电源按模块额定值接，输入到 MCU 的电平须兼容 3.3 V。POWER2_CTRL（PH3）启动为高，不代表外部动力电源已存在。

5840 PWM 为低有效，零占空比时信号保持高；左 50 kHz、右 25 kHz。FR / BRK 为开漏，BRK 拉低刹车。开环点动没有角度闭环限位，须留出机构行程。

## 灯音、诊断与预留

| 接口 | 引脚 | 当前功能 |
|---|---|---|
| 左 WS2812 DIN | J27-1 / PA8 / TIM1_CH1；J27-3 GND | 左侧 21 颗，DIN 靠车头；J27-2 不接 |
| 右 WS2812 DIN | J33-1 / PE14 / TIM1_CH4；J33-3 GND | 右侧 21 颗，DIN 靠车头；J33-2 不接 |
| 蜂鸣器 | PH6 / TIM12_CH1 | 板载无源蜂鸣器 |
| UART7 TX / RX | J38-3 PE8 / J38-4 PE7；J38-2 GND | 接 USB-TTL RX / TX；115200、8N1；默认 FC 诊断 |
| 金属盘预留 UART8 RX / TX | J37-4 PE0 / J37-3 PE1；J37-2 GND | 接盘 TX / RX；115200、8N1，尚无收发协议业务 |
| USART2 预留 TX / RX | J18-4 PD5 / J18-3 PD6；J18-2 GND | 仅基础初始化 |
| USART6 预留 TX / RX | J36-3 PG14 / J36-4 PG9；J36-2 GND | 仅基础初始化 |
| 原 SBUS J43 / USART1 | PB6 / PB7 | 本项目不初始化、不接遥控器 |

灯带独立供电并共地。J38-1 / J37-1 为 5 V，不要因串口接线形成重复供电；PC2 / J34-8 与 PC3 / J34-10 不承担当前金属盘业务。
