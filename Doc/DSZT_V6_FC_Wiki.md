# DSZT_V6_FC 项目 Wiki

本手册描述飞控专用固件，接线见 [A 板接线表](DSZT_V6_FC_接线表.md)。MAIN1 / MAIN2 是唯一运动指令来源；没有 MC7、SBUS、CH5 锁车或手动档。

## 1. 输入与释放

| 输入 | 反向 / 中位 / 正向端点 | 中位死区 | 正常闭环滤波 |
|---|---|---|---|
| MAIN1 行走 | 1260 / 1502 / 1770 μs | 1502 ± 50 μs | 1 点，最新有效值直通 |
| MAIN2 转向 | 1000 / 1500 / 2000 μs | 1500 ± 15 μs | 8 点滑动均值 |

MAIN1 正值前进、负值后退；MAIN2 负值左转、正值右转。死区内目标为零，死区外分段线性映射到 ±1000‰；标定端点外但仍合法的脉宽钳位为满幅。基础行走上限为 4900 ERPM，可用 `CHASSIS_OID_COMMISSION_MAX_ERPM` 收紧，不存在 CH7 限速。

两路有效范围均为 800～2200 μs，超过 30 ms 无有效脉冲判超时；上电及输入故障恢复后须各自连续 4 个有效样本预热。范围错误保留 5 ms，累计坏脉冲和超时事件不会因为后续好帧立即消失。

上电固定进入 `AUTO_FC` 流程；原始与滤波脉宽都在中位、连续 200 ms 且两路有新的有效样本，才释放命令层。转向层另有 200 ms 回中释放检查，因此应保持中位直到 `ui=6`，而非只看到 `rel=1` 就发车。OID、转向、参数门仍须同时满足。

任一路输入失效都会清除运动授权和待发非零目标，请求双 OID 零速，转向停止并刹车，不主动回正。恢复后重新双回中；转向编码器运行中失效或角度越限的硬故障不自动清除，需排除原因后重启控制板。

**PWM 不能传达飞控 armed 状态，也不能检测持续输出的合法但错误的非零指令。飞控未解锁/失控时必须输出中位或停止脉冲；独立物理动力切断仍必需。** 软件停车请求不是机械瞬停或驻车制动承诺。

## 2. 控制链路与机械参数

```text
MAIN1 → 最新有效脉宽 → 死区/线性映射 → 4900 上限 → 基础 ERPM
MAIN2 → 8 点均值 → 死区/线性映射
        ├─ 速度收角 → 阿克曼轮角 → 连杆轴角 → 300°/s 限速 → 双位置环 → 5840
        └─ 独立差速指令限速 1.6/s → 速度收角 → 前轮路径半径比例
基础 ERPM × 左右比例 → 健康/释放门 → USART3 / RS485 → OID 内部速度环
```

MAIN1 主链路没有额外均值或 MCU 纵向加减速斜坡。正常快速换向不等待速度反馈回零；最终加减速由 OID 内部斜坡完成。差速限速只影响左右分配，不用于平滑公共油门。

| 参数 | 当前值 |
|---|---|
| 轴距 / 前轮距 / 后轮距 | 610 / 500 / 500 mm |
| 轮胎外径 / 宽度 | 235 / 90 mm，使用者提供；轮径不参与当前 ERPM 控制链 |
| 编码器软件零点 | 左 3189、右 3073；12 位原始值，均已配置确认 |
| 零油门满幅内 / 外轮角 | 28° / 20.320382° |
| 对应内 / 外输出轴目标 | 76.125212° / 66.915019° |
| 轴角目标 / 反馈保护 | 80° / 82°；超过即故障，不是强行钳位 |
| 连杆轴角/轮角比例 | 内轮 89.719 / 33；外轮 82.325 / 25，不能随最大轮角一起缩放 |
| 位置环 | Kp=22‰/°；普通停止/重启误差 3°/5°，回中 4.5°/7°；PWM 目标 300～1000‰，每 10 ms 最大变化 50‰ |
| 速度收角 | 按有效行走目标幅值调度，零速增益 1.0，4900 ERPM 时 0.70；不是按实测车速闭环调度 |

前轮阿克曼模型：令内轮角为 δ，轴距 L、前轮距 W，内侧前轮中心在后轴线上的投影点到转弯中心的距离为 `r=L/tan(δ)`；后轴中心到转弯中心的距离为 `R=r+W/2`。两者不是同一个半径。外轮角为 `atan(L/(r+W))`；前内轮轨迹半径为 `sqrt(L²+r²)`，前外轮轨迹半径为 `sqrt(L²+(r+W)²)`。外轮速度比例为 1，内轮为两半径之比；左右转时互换，倒车保留相同比例并改变速度符号。

当前零油门满舵（L=0.610 m、W=0.500 m、δ=28°）：内侧投影半径 `r≈1.147 m`，后轴中心半径 `R≈1.147+0.250=1.397 m`；前内/外轮中心半径约 1.299 / 1.757 m，内/外速度比约 0.73970。这些是几何模型值，不是车身扫掠半径或实测转弯半径；实车操控测试通过不等于无侧滑模型已被逐项测量验证。

结构与各半径定义见 [参数示意图](assets/dszt-v6-fc-geometry.svg)。最高直行目标 4900 ERPM、14 极对对应轮毂 350 RPM；以 235 mm 外径和纯滚动计算，`v = (4900/14) × π × 0.235 / 60 ≈ 4.31 m/s = 15.50 km/h`，不是带载实测极速。4900 ERPM 行走目标下的满舵内轮角为 19.6°，因此该车速与 28° 最小几何半径不属于同一工况；胎宽、车身与探测盘外廓未计入上述半径。

## 3. 单轮开环零点标定

修改 [chassis_config.h](../application/chassis/chassis_config.h) 的 `CHASSIS_STEER_CALIBRATION_SIDE`：`0` 正常双闭环、`1` 左开环、`2` 右开环，当前为 **0**。修改后需编译和另行授权烧录；UART7 无运动模式切换或写零点命令。

1. 固定架空或隔离行走动力；MAIN1 持续保持 1502 μs 中位，MAIN2 先保持 1500 μs，待输入和转向释放。
2. 用 MAIN2 正负偏移点动选中转向电机，另一侧停机刹车。两个 OID 保持零目标但继续心跳；不要求 OID 在线才能标定。
3. MAIN2 回中即停；MAIN1 离中、任一路 PWM 异常立即撤销点动授权，恢复须重新双回中。默认标定 MAIN2 使用原始值，不经过 8 点均值。
4. `DBG MT6826S` 查看 `raw=左/右`，机构直行且读数健康稳定时，将对应值填入 `CHASSIS_STEER_LEFT_ZERO_RAW` / `RIGHT_ZERO_RAW`，保持对应确认宏为 1。
5. 标定后把 SIDE 改回 0，再编译。零点只保存在固件宏中，不写编码器 NVM，不按每次上电位置自动取零。

开环 PWM 范围 250～450‰；改变方向前停 300 ms，切 FR 后再等 300 ms。`CHASSIS_STEER_CAL_REQUIRE_ENCODER_HEALTH=0` 仅允许开环点动不受编码器在线门影响；**没有开环角度保护，不得长时间顶住机械止挡**。正常闭环始终要求双编码器健康和零点有效。

## 4. 软件架构、调度与 OID

`Core` 为 CubeMX 外设 / RTOS 入口；`application` 负责命令、底盘、灯音和诊断；`bsp` 负责 UART、RS485、回调分发、蜂鸣器；`modules` 为 PWM 输入、编码器、位置环、OID 和灯带驱动。没有 SBUS 接收模块。

外设初始化 → `RobotInit()` → FreeRTOS `defaultTask`。任务按 Command → Chassis → Lighting → Buzzer → Debug 顺序运行，然后 `osDelay(1)`；这是约 1 ms 服务循环，不是所有路径硬实时 1 ms 保证。HAL 时基 TIM6，RTOS tick 1 kHz；任务栈 1024 words，RTOS heap 30000 B。

| 调度项 | 当前设置 |
|---|---|
| 命令输入 / OID 总线服务 | 每次 RobotTask；输入故障先撤销旧目标，再服务 OID |
| 底盘目标 / 转向位置环 | 10 ms |
| OID 心跳 | 每侧目标间隔 100 ms，全程保持；驱动器配置超时 1000 ms |
| OID 帧间隔 / 收帧空闲 | 至少 8 ms / 2 ms；单总线串行处理，不中途截断在途响应 |
| OID 状态组 / 响应超时 | 100 ms / 50 ms，左右首发侧交替 |
| OID 状态安全超时 / 心跳断档预警门 | 500 ms / 800 ms；启动状态宽限 1000 ms |
| 零目标刷新 | 停车时约 100 ms 重发，不靠停止心跳停车 |
| 额外模式/目标回读 | 仅飞控双回中、软件目标为零、双侧反馈新鲜且低速并有总线预算时；不在行走中额外查询 |
| 灯带 / UART7 | 灯带 50 ms；OID 视图 100 ms，其他周期视图 200 ms；忙时跳过，不等待发送完成 |

OID 左地址 1、右地址 2，方向已由驱动器适配，软件系数均 +1；驱动器最大速度 4900 ERPM，速度环加减速 4900 ERPM/s，霍尔方案不执行 ABZ 找 Z。固件不覆盖上位机电机适配参数。

源码 [front_drive.c](../modules/drive/front_drive.c) 仍保留完整 ABZ 找 Z 状态机及 `z_fault_rearm_required` 锁存/重臂逻辑，并未删除；当前 [front_drive.h](../modules/drive/front_drive.h) 的 `FRONT_DRIVE_AUTO_Z_SEARCH=0`，初始化直接设为 Z READY 且清除该标志，正常调度不进入找 Z 路径。当前霍尔运行不依赖 Z；不要把此开关当作可直接启用的普通调参项，改成 1 必须重新核对编码器硬件、应用恢复入口和运动安全。

OID 断档或模式失配恢复沿用清旧目标 → 心跳恢复 → 再清零 → 等待上层重新健康回中 → 双侧新鲜零速验证。运行中不会因转向回中擅自取消心跳，也不引入永久停车故障锁存。

## 5. UART7 调试

115200、8N1、ASCII，命令以 CR 或 LF 结束。默认 `DBG FC`；运行期切换不持久保存。所有命令只读，不改变运动参数或执行器输出；`DBG SBUS` 已移除，返回错误。

| 命令 | 用途 |
|---|---|
| `DBG FC` | 飞控脉宽、健康、释放过程和目标 |
| `DBG MT6826S` | 编码器原始值、轴角、闭环及开环标定 |
| `DBG OID` | 双驱动器目标、反馈、总线、心跳及恢复状态 |
| `DBG GENERIC` | 综合视图，行前缀 `V6_FC` |
| `DBG OFF` | 停止周期输出；仍可接受查询或切换 |
| `DBG?` / `DBG HELP` | 当前视图编号及命令帮助；0=GENERIC、1=OID、5=MT6826S、7=FC、255=OFF |

### FC 与公共字段

`t` 为毫秒 tick；`mode`：2 自动、3 单轮标定；`gate`：0 就绪、1 输入无效、2 等待双回中/控制禁用、3 标定时 MAIN1 未回中。`src` 表示双路当前有效，`rel` / `released` 表示命令层释放。`center=1` 要求 **MAIN1/MAIN2 两路健康，且各自原始值与滤波值均在中位死区**，对应 `healthy && drive_centered && steer_centered`；健康还要求两路在线、故障码为 0，且本轮未检测到新的非法脉冲或超时累计事件。因此原始值看似回中而输入不健康时，`center` 仍为 0。`waitms` 为命令层回中计时，`events` 为累计输入异常事件。

`main1` / `main2`（综合视图为 `fc1` / `fc2`）依次是 **原始 μs / 滤波 μs / 在线 / 故障码**。故障码：0 正常、1 未就绪、2 超时、3 范围错误、4 预热。`good` / `bad` 为两路有效 / 非法脉冲累计数，`gap` 为累计超时断流事件数，`age` 为距最后有效脉冲的 ms，`badus` 为最后非法脉宽；这里均按 MAIN1 / MAIN2 排列，不是左右车轮。`thr` / `steer` 为 ±1000‰ 目标，`lim` 为基础 ERPM 上限，`en` 为整车行走授权，不能单凭 `rel=1` 判断整车就绪。

### 编码器字段

所有双侧字段均左/右排列。`cal`：0 闭环、1 左开环、2 右开环；`encgate` 为标定编码器健康门。`sr` 转向释放、`sf` 转向锁存故障、`raw` 12 位原始值、`sh` 编码器健康、`zero` 零点有效。`ang` 实际相对轴角、`at` 轴角目标，单位均为 **0.1°**；`duty` 为‰，`brk=1` 刹车、`dir` 为 FR 方向状态。`sched` 为收角后的转向量，`gain` 为速度收角增益‰。上述轴角不是实际轮胎角。

### OID 字段

| 字段 | 含义 |
|---|---|
| `id / param / en` | 左右 ID / 参数确认 / 行走授权 |
| `tgt / spd / online / fault` | 软件目标 ERPM / 驱动器反馈 ERPM / 在线 / 驱动器故障码 |
| `age / hb / hbmax` | 状态年龄 / 距心跳发送时间 / 已观测最大心跳间隔，ms |
| `to / crc / bus` | 左右状态超时计数 / CRC 错误计数 / RS485 接收溢出与 UART 错误计数 |
| `sm` | 0 正常、1 心跳恢复前清零、2 恢复心跳、3 恢复后清零、4 待重臂、5 待新零速验证 |
| `cmd` | 待发标志 / 双侧命令步骤 / 紧急零速优先标志 |
| `rmode / rtgt / rage / rto` | 驱动器回读模式 / 内部目标 / 回读年龄 / 回读超时次数；不是本地目标缓存 |
| `zwr / sack / wmiss` | 零速提交计数 / 速度写应答计数 / 未确认写计数 |
| `exc / ec` | Modbus 异常累计 / 最近异常码 |
| `main1 / req / cap` | MAIN1 原始 μs / 差速前有效基础 ERPM / 临时上限，cap=0 为未附加 |
| `rev / rd` | 可选换向等待及有效样本组数 / 当前允许额外回读 |
| `tx / txt` | 最近向 UART 提交的速度值 / 提交 tick，不等于驱动器已执行 |
| `pre / stopf` | 保留兼容字段，当前正常逻辑为 0；没有永久停车锁存 |

综合视图复用以上公共、FC、OID、编码器字段；`oid` 为双侧在线。未获得过数据的年龄可能显示 `4294967295`，不是实际经过了这么久。

## 6. 灯带与蜂鸣器

两侧各 21 颗，DIN 靠车头。`ui` 对应统一软件状态，故障优先于动态灯效：

| ui / 状态 | 灯效 | 声音 |
|---|---|---|
| 0 FC 输入故障/未就绪 | 紫蓝色慢闪 | 曾健康上线后，持续故障 300 ms 开始每 4 s 双音；首次未接飞控不循环报警 |
| 1 转向故障 | 紫红双闪 | 每 4 s 三音 |
| 2 OID 故障/离线 | 红色慢闪 | 每 4 s 单音 |
| 3 配置禁止 | 紫色常亮 | 无周期提示 |
| 4 等待释放/重臂 | 琥珀呼吸 | 持续 5 s 后，每 5 s 低频短双音 |
| 5 单轮标定已释放 | 低亮紫色 | 无行走就绪音 |
| 6 自动链就绪 | 低亮蓝色底光 | 稳定 100 ms 后一次短上升三音 |

启动另有一次 260 ms 上升三音，只表示软件启动。FC、转向、OID 三类故障声音均在持续 300 ms 后启动；声音稳定延时不延迟运动保护。

仅 `ui=6` 时，前进目标显示向车头移动的白色渐变光段，后退目标显示向车尾移动的白色渐变光段；转向侧叠加羽化琥珀呼吸，白色段保持可辨，两端保留状态底色。灯效依据最终指令方向，不是对实际移动方向或转速的测量。

## 7. 验证边界

2026-10-08，使用者确认 DSZT_V6_FC 已经过多次落地测试，当前功能效果满足使用要求；这是本 FC 版本的实测确认，不是沿用原 V6 的验收结论。日常功能通过不代表所有故障注入、制动距离或极端工况均已专项验证。

默认异常处理未配置独立硬件看门狗，MCU 硬故障时不能保证转向 PWM 被及时撤销。部署须保留独立动力切断；变更飞控配置或接线后，应重新核对启动、断线、失控输出和恢复回中行为。
